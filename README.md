# NEXA Remote V4

Android application for consent-based remote screen sharing.

## Safety and permissions

- Screen capture starts only after the device owner approves Android's MediaProjection prompt.
- An ongoing foreground notification remains visible while sharing is active.
- The user can stop sharing from inside the app.
- Pairing is explicit; no hidden access or permission bypass is used.

## Project

- Package: `com.nexa.remote`
- Language: Kotlin
- Minimum Android: API 26
- Compile SDK: 35
